ÉVÉNEMENTS SPÉCIAUX

Les événements sont des phases temporaires qui modifient le monde : nouveaux ennemis, musiques, difficultés accrues et loot exclusif. Ils sont essentiels pour obtenir certaines meilleures armes, armures et accessoires du jeu. On distingue les événements pré-Hardmode et surtout ceux du Hardmode, beaucoup plus importants pour la fin de partie.

Armée de gobelins

Déclenchement

  • Aléatoire après certaines conditions
  • Peut aussi être invoquée manuellement

Objectif :

  • Survivre à l’invasion

Loot important :

  • Accès au Gobelin bricoleur (reforge des accessoires)
  • Objets de début/milieu de jeu

Invasion pirate

Déclenchement :

  • Hardmode
  • Objet pirate ou aléatoire

Difficulté :

  • Élevée si mal préparé
  • Ennemis rapides et nombreux

Loot clé :

  • Armes puissantes
  • Accès au PNJ Pirate
  • Argent en grande quantité

Astuce : se battre près de votre base facilite la défense.

Légion de givre (Frost Legion)

Déclenchement :

  • Hardmode
  • Utilisation d’un objet spécial

Caractéristiques :

  • Invasion rapide
  • Moins rentable que d’autres événements

Loot :

  • Objets décoratifs
  • Peu essentiel mais fun

Éclipse solaire

Déclenchement :

  • Aléatoire en Hardmode

Difficulté :

  • Très élevée
  • Ennemis ultra agressifs

Loot extrêmement important :

  • Armes de mêlée top-tier
  • Accessoires très puissants

Astuce : combatez dans un espace contrôlé ou semi-fermé.

Pumpkin Moon

Déclenchement :

  • Hardmode
  • Invoqué manuellement

Description :

  • Vagues d’ennemis de plus en plus puissants
  • Boss exclusifs

Loot majeur :

  • Armure Spooky (Summoner)
  • Armes très puissantes
  • Accessoires endgame

Frost Moon

Description :

  • Version glacée de la Pumpkin Moon
  • Encore plus difficile

Loot :

  • Armes extrêmement puissantes
  • Objets parmi les meilleurs du jeu

Folie martienne (Martian Madness)

Déclenchement :

  • Hardmode avancé

Description :

  • Ennemis technologiques
  • Vaisseaux volants

Loot clé :

  • Armes futuristes
  • Montures volantes ultra efficaces

Événements lunaires

Déclenchés après :

  • Victoire contre l’Adepte lunatique

Description :

  • 4 piliers (Solaire, Nébuleux, Vortex, Stellaire)
  • Chaque pilier correspond à une classe

Objectif :

  • Détruire les piliers
  • Déclencher le combat final contre le Moon Lord

Farming avancé & optimisation

Une fois les événements maîtrisés, le farming devient central.

Fermes utiles

  • Ferme à slimes
  • Ferme à pirates
  • Ferme à pixies
  • Ferme à clés de biome
  • Ferme d’événements lunaires

Farming de potions

  • Régénération
  • Endurance
  • Rage / Wrath
  • Gravitation
  • Vitesse

Optimisation

  • Reforge tous les accessoires
  • Construire des arènes spécialisées
  • Adapter ton équipement à chaque événement

Résumé des événements :

  • Ils sont essentiels pour l’équipement final
  • Très rentables mais dangereux
  • Demandent préparation et stratégie
  • Indispensables avant le Moon Lord
